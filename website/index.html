          The difference
          
Sitting still is a feature

          
Most bots trade all the time and lose money through fees. GrgTrading has to prove itself first: before every use the model is tested on data it never saw. It is only allowed to trade if its buy signals beat the base rate overall and in most individual periods.

          
On a random-walk market, the model correctly refused to trade in 7 of 8 test runs.

          Risk management
          
Built to lose small, not to gamble

        

        

          

            

              
            

            
Risk-based sizing

            
Each position is sized so that hitting the stop costs about 1% of equity, capped at 30% of the account.

          

          

            

              
            

            
Stops that follow price

            
ATR-based stop-loss and take-profit. The trailing stop moves up as price rises and locks in gains.

          

          

            

              
            

            
Daily loss pause

            
If the account drops more than 3–5% in a day, there are no new entries until the next UTC day.

          

          

            

              
            

            
Kill switch

            
A drawdown beyond the limit closes everything and stops the bot until you reset it yourself.

          

          

            

              
            

            
No withdrawal rights

            
The bot uses a trade-only API key. It can never move your money off the exchange.

          

          

            

              
            

            
Paper mode first

            
Starts with simulated money on real prices. Real money requires an explicit confirmation flag.

          FAQ
          
Questions people ask

        

        

          Does it guarantee profit?
          
No. No bot can. Most automated strategies lose money after fees. GrgTrading is designed to limit losses and avoid trading on noise. Test it in paper mode for weeks before using real money.

        

        

          How much money do I need?
          
Nothing for paper mode. For real trading, exchanges set a minimum order of about 5 USDT. The bot adds a 25% safety margin, so the practical minimum is about 6–7 USDT per position. python -m grgtrading check shows the exact figure.

        

        

          Can the bot steal or withdraw my money?
          
Not if you follow the setup. Create the exchange API key with spot trading only and withdrawals disabled, and restrict it to your server's IP.

        

        

          What happens if my computer turns off?
          
Stops are checked by the bot, so open positions are unprotected while it is offline. Run it on an always-on machine or a small VPS with Docker.

        

        

          Why isn't it trading?
          
Usually because the model found no reliable edge, which is the intended behaviour. It re-checks every 12 hours. Days without trades are normal.
