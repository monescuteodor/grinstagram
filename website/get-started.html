Get started

Running in five minutes

You need Python 3.11 or newer. The bot starts in paper mode: real prices, simulated money, zero risk.

1 Install

git clone https://github.com/monescuteodor/GrgTrading
cd GrgTrading
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

2 Configure

copy .env.example .env
# MODE=paper  SYMBOLS=BTC/USDT,SOL/USDT
# STARTING_BALANCE=50

3 Test & run

python -m grgtrading backtest
python -m grgtrading check
python -m grgtrading run

On a server: docker compose up -d keeps it running 24/7 and restarts it automatically.
